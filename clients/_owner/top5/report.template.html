Install. Confirm. Stay in control.

01 / Keep the seven files together

Five EX5 files, Install Top 5.bat and this HTML. Double-click the BAT on Windows. No source files, downloads, DLL permission or website connection are required.

02 / Enter your risk

Select the intended running MT5 from the numbered list; other terminals may stay open. Choose fixed USD or current-balance percentage, then enter the amount. Then type the exact Gold and Nasdaq 100 CFD symbol names from Market Watch, including broker suffixes. Submitting the final symbol starts setup for that account. Risk is per trade on each bot, not a combined exposure cap.

03 / Automatic setup

The BAT reads the saved account/server and current profile, restarts MT5 once and adds five EA charts using your entered symbols. The EAs enforce USD hedging compatibility on startup. Symbol names are not automatically verified. Existing EA management briefly pauses during restarts. Only the selected terminal is restarted; unrelated terminals stay untouched. Check the typed symbols carefully. Global AutoTrading stays unchanged; if already on, bots may trade immediately. Original charts/profile are retained. Automatic restart and attachment still require a recipient demo acceptance check.

There is no daily loss limit or shared open-risk cap in this package. At 1% per trade, five simultaneous positions can risk roughly 5% before fees, gaps or additional positions. Use demo first. If selected risk is below the broker minimum lot, the client bot uses that minimum and CAN EXCEED the selected risk.
Licence, renewal and open-position safety

Expiry blocks new entries and cancels each EA’s own pending entry orders; it does not remove the EA or intentionally liquidate existing positions. Stop, target, trailing and timed-exit management continue while MT5 is running, connected and trading is permitted. Disconnections can delay order cancellation. Broker-side stops remain important.

The compiled deadline uses UTC/broker time conservatively; a broker clock ahead of UTC can stop new entries a few hours early. Changing the BAT date or reopening it does not renew the EX5s. The owner must send replacement compiled files. This is offline expiry enforcement, not unbreakable DRM or instant remote revocation.

What exactly was tested—and what was not?
  • Client EX5 builds, $10,000 separate starting balance per EA, Exness-MT5Trial16, native MT5 real ticks and 150 ms execution delay. Two sizing scenarios using the same frozen strategy settings: fixed $100 and 1% current balance. Lot size rounds down; signals below the minimum lot are skipped. No optimization was performed for this package.
  • Each EA has a six-month run from March 30 and a three-month run from June 30, ending September 30 exclusive. The windows overlap and are not independent tests. The small number of trades for some EAs limits inference.
  • Broker bid/ask prices, recorded commissions and swap are included. No extra hypothetical commission was added. Another broker’s spreads, contract size, session timing, execution and fees can materially change results. US100 here is the USTEC CFD, not NQ futures. Gold Overnight includes an invalid-stop entry rejection on April 13; failed orders remain part of the tested execution, not removed observations.
  • The combined view adds net closing-deal P&L from independent EA runs onto one $10,000 reference balance. It is not a shared-account native backtest and does not model shared margin, floating equity, order interaction or account-wide compounding. In percentage mode, each EA sized against its own independent balance. Combined native equity drawdown is unavailable.
  • Closing deals are reconciled to native MT5 trade counts. Partial exits can count separately, not as independent setups. Tied closing timestamps are ordered by EA then exit ticket; combined streaks depend on that tie order.
  • Payoff ratio = average net winning trade / average absolute net losing trade. Expectancy = net P&L / closing trades. The daily Sharpe proxy uses closed-balance daily returns, zero cash rate and √252 scaling—not floating equity returns. Trades/day uses weekdays; trades/month uses 30.4375 calendar days.
  • Licence entry/exit controls are additional client protections. Tester mode permits historical research; the live/demo runtime enforces the compiled deadline. No live account was traded or changed to produce this package.

MetaTrader’s documented profile-start mechanism is used by the installer. Internet access is optional for this reference only.
