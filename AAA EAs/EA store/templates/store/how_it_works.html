Buy

Four steps to your licenses.

  1. Browse the catalogue. Every EA page shows its logic, limitations and cached MT5 evidence. Prices are {{ store_discount_percent }}% below the previous list prices.
  2. Build your cart. {{ pack_rule }}
  3. Checkout with USDT. Choose TRC20 or BEP20, then send the exact amount shown (base price plus a few unique cents) to the address or QR code. Wrong network or token means lost funds.
  4. Automatic confirmation. The store reads the public blockchain; after the required confirmations your order page shows one license key per bot and a download button for each.

Install

One BAT per bot.

  1. Extract the ZIP (EX5, SET with your key pre-filled, INSTALL … .bat, README, LICENSE) and double-click the BAT.
  2. Choose your MT5 terminal from the list and type your broker's symbol name (for example XAUUSD, XAUUSD.r or GOLD).
  3. Allow WebRequest for the Calyx license server in Tools → Options → Expert Advisors (done for you when MT5 was closed).
  4. Load the profile File → Profiles → “Calyx – bot name”, enable “Allow Algo Trading” on the EA (F7 → Common) and the Algo Trading button — only when you are ready. The installer never switches trading on.
  5. Check the chart. The Experts tab shows “Calyx license: activated for account …”. The license is re-checked every 24 hours with a 72-hour offline grace.
