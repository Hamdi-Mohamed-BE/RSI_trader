# H4 fair-value-gap swing — frozen raw specification

Frozen before any return is inspected. One identical rule set is applied to XAUUSD and USTEC (US100). This is a mechanical interpretation of the user-supplied transcript, not a claim that it reproduces Remy's discretionary/private strategy.

1. Work only from completed broker-server H4 candles. With candle 1 oldest and candle 3 newest, a bullish FVG exists when candle 3 low is strictly above candle 1 high. Its zone is candle 1 high through candle 3 low. A bearish FVG exists when candle 3 high is strictly below candle 1 low; its zone is candle 3 high through candle 1 low.
2. Candle 2 does not need a minimum body or displacement because the transcript specifies only the three-candle wick gap. No trend, session, news, volatility, volume, daily or lower-timeframe filter is invented.
3. The zone becomes available only after candle 3 closes. Keep the newest untraded bullish and newest untraded bearish zone; a newer same-direction FVG replaces the older one. There is no time expiry because none was specified.
4. Enter on the first subsequent executable tick inside the zone. If price crosses completely through the far edge before a valid entry, invalidate it. One attempt per zone and one open strategy position per symbol.
5. For a bullish FVG, stop one tradable tick below candle 1's low. For a bearish FVG, stop one tick above candle 1's high. Target is fixed at 2R from requested executable entry. The transcript does not specify stop or target, so the familiar structural-stop/2R convention is an explicit raw assumption.
6. Both long and short setups are tested symmetrically. No break-even, trailing, partial exits, time exit, session close, martingale, grid, or adaptive portfolio controls.
7. Independent $10,000 USD start for every symbol/window; 1% current-equity planned stop risk. Lots round up to the broker step and use the minimum tradable lot when necessary, so actual risk may exceed 1%. Commission is outside the sizing budget and is included in results with swap and spread.
8. Native isolated Exness Strategy Tester, XAUUSD and USTEC, H4 chart, real-tick mode requested, 1 ms execution delay. Windows end 2026-09-05 exclusive: 6m, 1y, 3y and 5y. Longer missing real ticks are generated by MT5.

No parameters are optimized. Implementation corrections require all final runs to be regenerated; performance must not influence the frozen rule set.
