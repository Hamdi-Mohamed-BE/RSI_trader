# Any-balance launcher

**INSTALL AND RUN ON 900 USD MT5.bat** calls the same adaptive twelve-bot installer as the other BAT files. It is not restricted to a USD 900 balance.

The default planned risk is 1% per EA trade. On USD 900, that is approximately USD 9 per bot, subject to broker minimum volume, gaps and slippage. Twelve simultaneous positions could stack planned exposure to roughly 12%.

Run the portfolio on demo before using real funds.
